# Governance

AI Black Hole is an open-source project maintained in the open.

## Current decision process

The repository owner and maintainers are responsible for project direction, releases, security response, and final merge decisions. Contributors are encouraged to discuss substantial changes in an issue before implementation.

Decisions should be based on user value, technical evidence, maintainability, compatibility, and the project's security principles. Significant architectural or security-sensitive decisions should be recorded in `docs/DECISIONS/`.

## Contribution review

Pull requests require maintainer review. CI must pass before merge unless a maintainer documents a justified exception. Security-sensitive changes require explicit review of threat assumptions, resource bounds, false positives, isolation, privacy, and rollback.

## Becoming a maintainer

There is no automatic promotion process. Maintainer responsibilities may be delegated based on sustained, high-quality contributions, sound security judgement, respectful collaboration, and demonstrated ability to review changes. Maintainer access is granted explicitly by the project owner.

## Changes to governance

Governance changes should be proposed through a public issue and pull request. The project owner makes the final decision while explaining material trade-offs.
