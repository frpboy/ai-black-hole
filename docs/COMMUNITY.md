# Community guide

AI Black Hole is built in the open. We welcome bug reports, tests, documentation, integration examples, design reviews, and thoughtful security feedback.

## Expectations

- Be respectful and assume good intent.
- Critique ideas and implementation, not people.
- Share evidence and reproducible examples.
- Keep reports focused and avoid posting sensitive data.
- Respect maintainer decisions and project scope.
- Disclose security issues privately.

## Ways to contribute

1. Improve documentation or examples.
2. Reproduce and test an existing bug.
3. Add focused unit and integration tests.
4. Review an issue's acceptance criteria.
5. Implement a scoped issue after confirming with a maintainer.
6. Propose an adapter or architecture change with evidence.

## Recognition

Contributors are credited through Git history and release notes where appropriate. Contribution does not imply employment, endorsement, maintainer status, or guaranteed compensation.

See [Contributor onboarding](CONTRIBUTOR_ONBOARDING.md), [Governance](../GOVERNANCE.md), and [Code of Conduct](../CODE_OF_CONDUCT.md).
