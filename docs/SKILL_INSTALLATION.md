# Skill Installation

The canonical agent-neutral skill is [../skills/ai-black-hole/SKILL.md](../skills/ai-black-hole/SKILL.md).

Skill discovery and installation conventions differ between coding-agent hosts and versions. Do not assume one directory layout is automatically recognised by every agent.

## Manual use

1. Open the skill file in your coding agent's supported custom-instructions or skill mechanism.
2. Make referenced documents available to the agent.
3. Ask it to audit the current repository before changing files.
4. Review its proposed plan and approve changes explicitly.
5. Inspect the diff and run project tests.

Host-specific packaging instructions will be added after each host's current official format has been verified.
