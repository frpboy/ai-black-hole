# Support

Thanks for using AI Black Hole.

## Where to ask

- **How-to questions and integration help:** open a discussion if GitHub Discussions is enabled. Otherwise, open an issue using the documentation template and describe the exact point where you are blocked.
- **Reproducible bugs:** use the Bug report issue form.
- **Feature proposals:** use the Feature request issue form.
- **Security vulnerabilities:** do not open a public issue. Follow [SECURITY.md](SECURITY.md).

## Include useful context

Please include the project version or commit, runtime and framework versions, a minimal reproduction, expected behaviour, and actual behaviour. Use synthetic data and redact credentials, cookies, tokens, personal data, hostnames, and production payloads.

## Scope

This is a community-maintained open-source project. Support is provided on a best-effort basis; no response time or compatibility guarantee is implied. Please be respectful and help others by sharing a minimal, reusable reproduction when possible.
